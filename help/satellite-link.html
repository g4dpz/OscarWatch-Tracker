Overview

Satellite link is OscarWatch’s replacement for the legacy SatPC32 DDE interface. When enabled, OscarWatch runs a small WebSocket server on your PC that sends JSON messages about the focused satellite: name, NORAD ID, uplink and downlink frequencies and modes, ADIF bands, azimuth, elevation, range, and more. Logging applications can subscribe and pre-fill QSO fields automatically.

Each message also includes a wispDde string in the old Wisp32/GSC format for adapters that still expect SatPC32-style text.

Settings

Open Settings → Integrations → Satellite link. Press Save when finished. See also Settings (Integrations).

  • Enable Satellite link WebSocket server — master switch.
  • Port — default 7373 (1024–65535).
  • Allow connections from local network — when off, only programs on this PC can connect (127.0.0.1). When on, any device on your LAN may connect; check your firewall.
  • Only broadcast when satellite is above horizon — when on, payloads below 0° elevation send ** NO SATELLITE ** (SatPC32-style).
  • Update interval (ms) — minimum time between identical payloads (default 1000). Focus and mode changes are sent immediately.
  • Test port — checks that OscarWatch can bind to the port (no client required).
  • Open help — opens this page.

Status bar

When Satellite link is enabled, the main window status bar shows a Sat link label to the left of the map-time buttons:

  • amber — listening, no clients connected yet
  • green — one or more clients connected (hover for port and client count)
  • amber / error — could not start (port in use, permissions, etc.)

The indicator is hidden when Satellite link is disabled in Settings.

For developers

Protocol version 1. Connect with a standard WebSocket client to:

ws://127.0.0.1:<port>/ (this PC only)

or, when LAN access is enabled:

ws://<this PC IP>:<port>/

There is no authentication in v1 — use localhost or a trusted LAN only. On connect, OscarWatch sends the latest snapshot immediately, then broadcasts updates when focus, mode, frequencies, or tracking data change (throttled by the update interval).

Message format

One UTF-8 JSON object per WebSocket text frame:

{
  "type": "satelliteStatus",
  "version": 1,
  "timestampUtc": "2026-07-07T11:04:00.000Z",
  "inRange": true,
  "satellite": {
    "name": "SO-50",
    "noradId": "27607",
    "modeType": "FM VOICE"
  },
  "frequencies": {
    "uplinkHz": 435300000,
    "downlinkHz": 145850000,
    "uplinkMode": "FM",
    "downlinkMode": "FM",
    "nominalUplinkKHz": 435300,
    "nominalDownlinkKHz": 145850,
    "isBeaconOnly": false
  },
  "bands": { "tx": "70cm", "rx": "2m" },
  "tracking": {
    "azimuthDeg": 91.7,
    "elevationDeg": 1.9,
    "rangeKm": 2100.5,
    "rangeRateKmPerSec": -4.92,
    "isSunlit": true
  },
  "dopplerStrategy": "full",
  "wispDde": "SO-50 AZ91,7 EL1,9 UP435300000 UFM DN145850000 DFM MA0,0 RR-4,92"
}

When no satellite is in range (or none focused):

{
  "type": "satelliteStatus",
  "version": 1,
  "timestampUtc": "...",
  "inRange": false,
  "satellite": null,
  "wispDde": "** NO SATELLITE **"
}

Field notes

  • satellite.name — OscarWatch / LoTW naming (same as Cloudlog sat_name).
  • frequencies.uplinkHz / downlinkHz — radio-corrected Hz (what CAT uses), not raw catalogue nominals.
  • dopplerStrategy — full, downlinkOnly, or uplinkOnly.
  • wispDde — European decimal commas; SatPC32 field order for legacy parsers.
  • Ignore unknown future JSON fields (forward-compatible).

Minimal Python client

import asyncio
import json
import websockets

async def main():
    async with websockets.connect("ws://127.0.0.1:7373/") as ws:
        while True:
            msg = json.loads(await ws.recv())
            if msg.get("inRange"):
                sat = msg["satellite"]["name"]
                rx = msg["frequencies"]["downlinkHz"]
                print(f"{sat} RX {rx} Hz")
            else:
                print("No satellite")

asyncio.run(main())

Minimal C# client

using System.Net.WebSockets;
using System.Text;
using System.Text.Json;

using var ws = new ClientWebSocket();
await ws.ConnectAsync(new Uri("ws://127.0.0.1:7373/"), CancellationToken.None);
var buffer = new byte[8192];
while (ws.State == WebSocketState.Open)
{
    var result = await ws.ReceiveAsync(buffer, CancellationToken.None);
    var json = Encoding.UTF8.GetString(buffer, 0, result.Count);
    using var doc = JsonDocument.Parse(json);
    var root = doc.RootElement;
    if (root.GetProperty("inRange").GetBoolean())
        Console.WriteLine(root.GetProperty("satellite").GetProperty("name").GetString());
}

Troubleshooting

  • Port in use — another program (or a second OscarWatch instance) may already use the port. Change the port or stop the other program. Use Test port in Settings.
  • LAN clients cannot connect — enable Allow connections from local network, allow the port in Windows Firewall, and use this PC’s LAN IP address.
  • Always ** NO SATELLITE ** — check Only broadcast when satellite is above horizon, focus a satellite on the map, and ensure a transponder mode is selected in the frequency panel.
  • No clients shown in status bar — the server can be listening with zero clients; connect your logging app and the label should turn green.

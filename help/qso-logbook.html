OscarWatch includes a lightweight local QSO logbook for satellite contacts. It is separate from Cloudlog integration (under Settings → Integrations; frequencies and checks rove grids online). Use the logbook when you want quick field logging tied to the satellite you are tracking, then export ADIF for your main logging program.

Opening the logbook

Go to Tools → QSO Logbook. Only one logbook window is open at a time — choosing the menu again brings the existing window to the front. The window opens with the callsign field ready for fast entry. Keep it open beside the main map during a pass.

Before you log

  • My callsign and grid — each logbook stores its own station identity for ADIF export (STATION_CALLSIGN and MY_GRIDSQUARE). Set these when you create a logbook or edit them by creating a new logbook for a different activation. They are not taken from Settings → Station (that tab is for pass prediction position and display labels only).
  • Focus a satellite — click the spacecraft on the map or in the pass list. The logbook’s Station control panel shows satellite name, mode, and uplink/downlink frequencies from OscarWatch tracking. These are stored automatically when you add a QSO.

Logbooks

Contacts are grouped into named logbooks (for example “Portable activation” or a contest name). Use the Logbook menu to switch between them — the current logbook name is shown at the top of the menu, with a radio list of all logbooks below.

  • New logbook — opens a dialogue where you enter a name, your callsign, and your grid for that activation. If a logbook is already selected, its callsign and grid are offered as a starting point.
  • Delete logbook — asks for confirmation, then removes the selected logbook and all QSOs in it (there is no undo).

The first time you open the logbook, OscarWatch creates a default Main logbook using your Maidenhead grid from Settings → Station. Enter your callsign via Logbook → New logbook or by recreating the main logbook with the correct details.

UTC logging

Every QSO is timestamped in UTC when you press Add. The live QSO time (UTC) clock shows the time that will be recorded, formatted using your regional date order and your 12- or 24-hour clock preference from Settings. History columns and ADIF export use UTC (QSO_DATE / TIME_ON). The date/time format in the grid follows the same display preferences.

Fast entry

  • Type the worked callsign, RST sent/received, grid, optional name and comment. Callsign and gridsquare entries are uppercased as you type.
  • Press Add, or press Enter in any entry field — the QSO is saved and focus returns to the callsign box for the next contact. Add is disabled until the callsign is filled in and any gridsquare entry is valid (empty grid is allowed).
  • RST defaults to 59 on FM/packet-style modes and 599 on SSB/CW, based on the tracked mode.
  • When you type a callsign you have worked before in this logbook, a red Worked badge appears under the entry row (green Not worked for a new call). The callsign box border uses the same colours. A hint may also show the previous grid.
  • Typing three or more characters in the callsign box filters the recent QSO list to matching calls (cleared when you finish logging or clear the field).
  • Alt+W clears the entry fields (and cancels an edit in progress), then returns focus to the callsign box — similar to contest loggers such as N1MM.

Grid squares on a line

For a station on a Maidenhead grid boundary, enter multiple squares separated by commas (for example IO77,IO87). This applies to the worked Gridsquare field and to My grid when you create a logbook. Values are normalised to uppercase. The gridsquare border turns green when the entry is valid and red while it is incomplete or invalid.

Recent QSOs

The history grid lists contacts for the selected logbook (newest first). Columns include date/time, call, grid, satellite, mode, RST sent, RST received, and comment. Click a row to select it, or right-click a row for Edit QSO and Delete QSO. Drag column borders to change widths, and resize or move the window — OscarWatch remembers your layout when you close the logbook.

  • Edit → Edit QSO — loads the selected contact into the entry fields so you can correct it and press Save.
  • Edit → Delete QSO — asks for confirmation, then removes the selected contact.

Export ADIF

Choose Export → Export ADIF to save the current logbook as a .adi file. Records include satellite name, mode, bands, frequencies, propagation mode SAT, your station callsign and grid from the logbook, and comma-separated grids when used. Special characters in comments are escaped for safe ADIF import. Import the file into Cloudlog, Log4OM, or any ADIF-capable logger.

Where data is stored

Logbooks and QSOs are kept locally in:

%AppData%\OscarWatch\qso_logbook.db

Window size, position, and history column widths are saved in %AppData%\OscarWatch\settings.json when you close the logbook window.

Back up the database file if you rely on OscarWatch as your only copy of a field log. ADIF export is the recommended way to merge contacts into your main log.

Tip: Cloudlog’s Logbook dropdown under Settings → Integrations is for online grid checks on hams.at roves — not the local QSO logbook described here.

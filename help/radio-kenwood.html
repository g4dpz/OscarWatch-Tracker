The TS-2000 is supported as a single satellite radio (Beta). OscarWatch drives SATL over Kenwood ASCII CAT (SatPC32-style SA / FA / FB), including entry on pass start and exit when you quit or disconnect.

Before each pass (or once per session)

  1. Close any radio menus. Leave memory mode off on VFO A/B if you can — OscarWatch also clears memory mode via CAT when needed.
  2. Putting the radio in SAT on the front panel before tracking is still the most reliable start; OscarWatch will then confirm and maintain SATL over CAT.
  3. In OscarWatch: Settings → Radio — rig type TS-2000, correct COM port and baud (57600 8N1; OscarWatch asserts hardware RTS for CAT replies).
  4. Pick the satellite and transponder mode in the frequency panel.
  5. Press Resume (not Standby) and start tracking.

What OscarWatch controls

  • SATL entry and layout (SA), then receive/transmit frequencies via FA/FB (Doppler and your offsets).
  • Modes where the driver supports them for the selected transponder (bracketed with SAT CTRL so uplink stays on Sub).
  • CTCSS on FM satellites when configured.
  • Link-hold reads (~1/s FA;) while tracking, matching SatPC32 habits.
  • Satellite mode exit when you quit or disconnect, then COM port close with RTS/DTR dropped so USB serial adapters release cleanly.

OscarWatch does not change RF power — set watts on the radio yourself.

If SATL cannot be confirmed via SA;, OscarWatch continues FA/FB tracking in a degraded state and avoids falling back to ordinary FR split commands. Check the radio front panel and leave menus closed.

Tuning tips

  • Linear SSB — use passband trim on the receive VFO; Doppler follows your offset.
  • Adjust Doppler thresholds if tracking feels sluggish near TCA.
  • Pause CAT in Settings if you want full manual control for a while.

Receive-only and same-band

  • Beacons / SSTV (uplink 0): OscarWatch keeps SATL and Doppler-tracks the downlink on FA only (Sub / FB is left parked). This avoids leaving SAT and losing Doppler on the TS-2000.
  • Same-band modes (uplink and downlink within 10 MHz, e.g. ISS Packet): OscarWatch turns SATL off and uses split (FR0;FT1;), as on other non-cross-band passes.

See also receive-only overview (ICOM behaviour differs — sat mode off for beacons).

The Doppler pass insights tool lets you load a recorded pass log (CSV) and see a detailed time-series chart of how your Doppler threshold, CAT delay, and lead settings performed during that pass. You can also load a second pass to compare settings changes side by side.

Opening Doppler pass insights

Go to Menu → Help → Doppler pass insights to open the window. It will show a list of recent pass logs stored in your local doppler-logs folder.

Loading a pass log

Click Open CSV to browse to any Doppler log file on your computer. Each row in the CSV records the status of one CAT write (or lack thereof) during the pass. OscarWatch displays:

  • Your selected pass file path
  • A summary of key metrics (RX/TX write rates, frequency deltas, peak slew)
  • A detailed time-series chart showing what happened second by second

Using "Load latest"

Click Load latest to quickly load the most recent pass log without browsing. This is handy if you just finished a pass and want to review it immediately.

Opening the logs folder

Click Open log folder to open your system file browser to the Doppler logs directory. On Windows, logs are stored in %AppData%\OscarWatch\doppler-logs\.

Reading the chart

The chart displays four colour-coded series over the entire pass duration:

  • Blue — RX frequency delta (how far off centre the calculated frequency was)
  • Orange — TX frequency delta (uplink shift)
  • Teal — Doppler threshold (the band where no CAT write happens)
  • Purple ticks — Individual CAT writes (when you commanded the radio)

The vertical axis shows frequency in Hertz; the horizontal axis shows elapsed seconds from start of pass.

Zooming and panning

Use the zoom buttons above the chart:

  • + — Zoom in (up to 16x magnification)
  • − — Zoom out
  • Reset — Return to full-pass view

When zoomed in, the chart becomes scrollable. Use the horizontal scrollbar to pan through different parts of the pass. You can also use Ctrl+scroll wheel to zoom. This lets you examine the steep middle of a pass in detail or see the approach and departure legs clearly.

Analysis tabs

Overview

The Overview tab displays a summary of the pass:

  • Summary — Satellite name, pass window, row count, snapshot count, CAT writes, and offset changes
  • Thresholds — Your configured threshold band and effective reduction percentage
  • Dynamics — Peak deltas (slew rate) and p95 percentiles (95th percentile delta, excluding the worst 5%)
  • Activity — Percentages of rows where CAT was writing, paused, or offset was changed
  • Recommendations — Suggestions for tuning (if the data indicates issues)
  • How to use this to tune radio settings — A four-step guide for making targeted improvements

Activity bars

Visual progress bars show:

  • RX writes — Percentage of rows where RX was updated
  • TX writes — Percentage of rows where TX was updated
  • Below threshold — Percentage of rows inside the threshold band (no write)
  • Interactive — Percentage of rows where manual offset changes happened

Recent events

A detailed event log showing every sampled point in time-order. Each entry shows UTC time, event type (calculated, written, offset change, etc.), RX and TX deltas, whether writes happened, threshold status, and any notes about what occurred.

Comparing two passes

To see if a settings change improved your pass, switch to the Files tab and click Open compare CSV. Load a second pass log. OscarWatch will:

  • Overlay the comparison pass on the chart as dashed lines
  • Show both passes' metrics in the primary summary
  • Calculate a verdict (better, worse, or mixed)
  • Display delta changes and recommend the next tuning step

Understanding the comparison verdict

The Comparison tab appears once you load a second pass. It shows:

  • Tick (✓) Better — Your second pass improved on 3 or more of these metrics: lower RX/TX write rates, lower p95 deltas, or more stable writes.
  • Cross (×) Worse — Your second pass got worse on 2 or more metrics. Consider reverting the change or trying a different adjustment.
  • Tilde (~) Mixed — One metric improved, one got worse. Usually means you need to fine-tune further (e.g. threshold went down but writes increased).

Delta details

The comparison shows exact changes for:

  • RX writes — Signed percentage change (e.g. +3.2% means more writes in the second pass)
  • TX writes — Signed percentage change
  • RX p95 — Signed Hertz change (e.g. -8 Hz means lower frequency drift)
  • TX p95 — Signed Hertz change

Below the deltas, OscarWatch suggests your next action:

  • Lower threshold or CAT delay slightly — More aggression would help; writes are stable but deltas are high
  • Raise threshold or CAT delay slightly — Reduce chatter; write rate is too high
  • Keep these settings — You have found good tuning; the pass looks solid
  • Make a small adjustment and compare again — Results are inconclusive; try one more tweak

Practical tuning workflow

  1. Record a baseline pass. Use your current Doppler settings during a satellite pass. OscarWatch logs the data automatically.
  2. Review with insights. Open Doppler pass insights and load the CSV. Check the chart and metrics. If the middle of the pass looks choppy or deltas are high, proceed to step 3.
  3. Make one small change. Go to Settings, Radio tab. Adjust Doppler threshold by 10-20 Hz, or toggle adaptive threshold, or tweak lead strength. Try only one change.
  4. Record a second pass. Work another satellite pass with your new settings.
  5. Compare the passes. Load both CSVs in Doppler pass insights using the Comparison feature. Check the verdict and delta details.
  6. Repeat or keep. If better, consider your next tweak or declare it done. If worse, revert and try a different direction.
Tip: Use passes on different satellites for a fair comparison. Passes on high-speed, steep satellites show Doppler effects more clearly than slow, shallow passes. Linear transponders (SSB/CW) reveal tuning differences better than FM cubesats.

Chart overlay legend

When comparing two passes, the chart shows:

  • Solid lines — Your primary pass (first loaded)
  • Dashed lines — Your comparison pass (overlaid for direct comparison)

If the dashed lines are close to the solid lines, the two passes tracked similarly. If they diverge, especially near TCA, your settings change affected the behaviour.

Exporting and logging

Doppler pass logs are plain CSV files stored in your local logs folder. You can:

  • Copy them for archiving or sharing
  • Open them in a spreadsheet to do custom analysis
  • Delete old logs to save disk space

Each filename encodes the satellite and UTC start time, for example: RS-44-26-06-22-13-46-doppler.csv

Keeping logs: Archive passes you are happy with (e.g. "RS-44-tuned-well.csv") so you can return to them later as reference baselines. This helps if you change settings on another satellite and forget what worked well before.
